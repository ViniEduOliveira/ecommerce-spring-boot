> Este repositório documenta a evolução de um projeto de e-commerce, que começou como um trabalho acadêmico em grupo e está sendo aprimorado individualmente para se tornar uma API REST profissional.

## 📖 Sobre a Origem e Evolução

O projeto teve início como um **sistema de gerenciamento de e-commerce via linha de comando (CLI)**, com persistência de dados em PostgreSQL através de JDBC puro. 

Atualmente, o sistema está passando por uma refatoração completa e sendo **evoluído individualmente** para uma **API REST** moderna. O objetivo desta nova fase é aprofundar os conhecimentos em arquitetura backend, boas práticas de desenvolvimento e consolidar o projeto como parte do meu portfólio pessoal.

## 🏗️ Estrutura do Repositório

Para preservar o histórico de desenvolvimento e demonstrar a evolução técnica, o repositório está organizado da seguinte maneira:

- 📂 **`/` (Raiz do projeto)**: Contém a versão atual em desenvolvimento (migração para *Spring Boot + JPA/Hibernate + PostgreSQL*).
- 📂 **`/legacy-cli`**: Contém a versão original (legada) desenvolvida em Java puro + JDBC para o trabalho acadêmico.

## 🚀 Tecnologias (Versão Atual)

A nova versão da API está sendo construída com as seguintes tecnologias e ferramentas:

- **Linguagem:** Java 21
- **Framework Principal:** Spring Boot
- **Persistência de Dados:** Spring Data JPA / Hibernate
- **Banco de Dados Produção:** PostgreSQL
- **Banco de Dados Testes:** H2 Database
- **Gerenciador de Dependências:** Maven
