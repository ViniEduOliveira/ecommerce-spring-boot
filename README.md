\# E-commerce API



Este repositório documenta a evolução de um projeto de e-commerce, começando como trabalho em grupo na faculdade e evoluindo individualmente para uma API REST profissional.



\## Estrutura



\- \*\*raiz do projeto\*\*: versão atual, em migração para Spring Boot + JPA/Hibernate + PostgreSQL

\- \*\*`legacy-cli/`\*\*: versão original em Java puro + JDBC, desenvolvida em grupo como trabalho acadêmico



\## Tecnologias (versão atual)



\- Java 21

\- Spring Boot

\- Spring Data JPA / Hibernate

\- PostgreSQL

\- H2 (testes)

\- Maven



\## Sobre a origem



O projeto começou como um sistema de gerenciamento de e-commerce via linha de comando (CLI), com persistência em PostgreSQL via JDBC. Está sendo evoluído individualmente para uma API REST usando Spring Boot, como parte de estudos e portfólio pessoal.
